# on a Pi 5 and on an ARMv6 Pi Zero W. Nothing that needs NEON, a compiler, or
# a desktop audio stack. Audio is arecord/aplay from alsa-utils (apt).

# GPIO is deliberately NOT here. The cradle switch needs gpiozero and a pin
# factory under it (lgpio on Bookworm), and pip's lgpio is a source dist: it
# swigs and compiles a C extension, so `pip install lgpio` fails on a clean Pi
# with "command 'swig' failed". Installing swig and python3-dev to get past
# that puts a build toolchain on every Pi, which is the thing this file exists
# to avoid.
#
# So GPIO comes from apt as prebuilt system packages, and install.sh builds the
# venv with --system-site-packages so it can see them:
#
#   sudo apt install python3-gpiozero python3-lgpio
#
# Nothing pip installs here needs a compiler, which is what keeps an ARMv6 Pi
# Zero W a copy and a config edit.
